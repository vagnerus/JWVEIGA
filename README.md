# JWVEIGA - Portal Corporativo & CPD

Portal inteligente e moderno para gestão e acesso rápido a links, sistemas internos, ferramentas CPD, painel administrativo multi-usuário e modo visitante.

## 🚀 Funcionalidades

- **Design Cyberpunk & Dark Mode Moderno:** Interface de alta performance, responsiva com efeitos neon e ícones FontAwesome.
- **Painel Administrativo:** Controle total de usuários, status (ativo/bloqueado), definição de tempo de expiração de acesso e criação/exclusão de contas.
- **Ambiente Individual por Usuário:** Cada usuário cadastrado possui sua própria grade de links personalizável.
- **Modo Visitante (Demo 10 min):** Acesso instantâneo sem necessidade de login com cronômetro em tempo real e auto-exclusão automática.
- **Visualizador / Miniatura Popup:** Pré-visualização integrada de links e páginas com atalhos de abertura e cópia rápida.
- **Gerenciamento de Perfil:** Permite a qualquer usuário alterar seu nome de usuário e senha a qualquer momento.
- **Backend Integrado em Python:** Servidor REST API nativo com persistência de dados em JSON.

## 💻 Como Executar

```bash
# Iniciar o servidor localmente
python server.py
```
Acesse no navegador: `http://localhost:8080` ou `index.html`.
